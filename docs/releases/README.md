# Release notes

One hand-written file per release, named after its tag (`v6.0.0.md`). When a
release is published, `release.yml` uses that file as the GitHub release body
and appends the commands for verifying the signed container image. A release
without a file here gets the changelog release-please wrote instead.

`CHANGELOG.md` at the repository root is generated by release-please from the
Conventional Commit subjects. These files are the readable version: what
changed for someone running LSADRA, what breaks, and what to do about it.

See [Releasing](https://github.com/tsmanral/lsadra/blob/main/CONTRIBUTING.md#releasing) for the whole process.
